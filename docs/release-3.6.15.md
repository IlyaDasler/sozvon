# Созвон 3.6.15 — ключ под текущим паролем

- `registerIdentityVault()` снова вызывается в main-процессе: старый локальный ключ импортируется без пароля.
- В настройках «Сквозное шифрование» появилась кнопка «Сохранить под текущим паролем». После загрузки ключа она перезаписывает серверную копию текущим паролем.
- Убран переходный обход проверки пароля для key-backup: сервер снова принимает только текущий или действительно прежний пароль из истории.
- Сохранены исправления окна поверх настроек, глазка, регистра и Argon2id.
