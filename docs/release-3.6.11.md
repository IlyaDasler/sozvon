# Созвон 3.6.11 — восстановление ключа и глазок пароля

- В настройках «Аккаунт» появилась кнопка «Восстановить ключ по паролю». Окно можно открыть после «Позже», без перезахода.
- Убран `text-transform: uppercase` с поля пароля; все password-поля не капитализируются ОС.
- Добавлена подсказка «Пароль чувствителен к регистру» и разные ошибки для неверного пароля и повреждённой копии.
- Глазок исправлен: закрытый глаз — пароль скрыт, открытый — показан.
- Старый текст «перенесите сюда ключ» заменён на восстановление по паролю.
