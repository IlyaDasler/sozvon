# Созвон 3.7.0

## Безопасность

- Первая публикация ключа E2EE требует пароль аккаунта; при включённом 2FA — TOTP.
- Замена ключа требует пароль и TOTP, остальные сессии завершаются.
- Сессии привязаны к секрету устройства: сервер хранит только SHA-256, украденный bearer-токен без секрета устройства не работает.
- Сброс пароля по почте для аккаунта с 2FA требует TOTP; после сброса все сессии завершаются.
- OAuth-аккаунт без пароля не может включить E2EE, пока не задаст пароль.
- Новые резервные копии ключа используют Argon2id; старые PBKDF2-копии поддерживаются.
- История ключей связана SHA-256-цепочкой; клиент проверяет целостность и кэширует последний корень.
- Манифесты обновлений подписываются Ed25519; клиент проверяет подпись встроенным публичным ключом.
- Key-backup API принимает только клиенты не старше 3.6.8.
- Добавлены HSTS и журнал событий безопасности.
- Добавлены security headers, HTTPS-only API, одноразовые WebSocket-тикеты, CORS и rate limit.

## Телефон

- Регистрация по номеру телефона и паролю.
- Подтверждение через Telegram Contact Share, без SMS.
- Привязка мобильного номера к существующей учётной записи тем же способом.
- Номер хранится на сервере только в виде HMAC, не в открытом виде.
