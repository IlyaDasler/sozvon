# Шифрованные резервные копии БД

Скрипт: `scripts/backup-encrypted.sh`.

- `sqlite3 .backup` создаёт согласованную копию.
- Копия шифруется GPG AES-256.
- Ключ: `/etc/sozvon-backup.key` (600 root).
- Каталог: `/var/backups/sozvon` (700 root), хранение 30 дней.
- Таймер: `sozvon-backup.timer`, ежедневно 03:30 UTC.

**Ключ `/etc/sozvon-backup.key` обязательно хранить отдельно от сервера.** Без него бэкапы не восстановить. Копию ключа нельзя коммитить в Git или пересылать в чат.
