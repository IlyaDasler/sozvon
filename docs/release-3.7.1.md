# Созвон 3.7.1

Исправлено открытие Telegram при регистрации и привязке номера.

- Если Telegram Desktop установлен, приложение запускает его напрямую и открывает нужного бота.
- Если Telegram Desktop не установлен, открывается веб-версия Telegram.
- Windows больше не показывает запрос «Получите приложение, чтобы открыть ссылку "tg"» и Microsoft Store.
- Ссылка на бота и код подтверждения не менялись.
