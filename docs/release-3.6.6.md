# Созвон 3.6.6 — комплексное усиление безопасности

- Разрешения Electron требует доверенную страницу, доверенный requester и main frame.
- Навигация главного окна разрешена только на упакованный renderer/index.html.
- PiP получил отдельный preload с минимальными правами; IPC проверяет отправителя.
- Удалённые API разрешены только по HTTPS; HTTP — только loopback.
- WebSocket принимает только доверенный origin.
- Link preview: защита от SSRF, userinfo и лимит запросов.
- Усилена проверка Telegram-контакта и привязки телефона.
- Смена ключа требует TOTP, если включён второй фактор.
- Добавлены security headers и private cache policy для /me.
- Обновлены зависимости и добавлены регрессионные тесты.
