# Свой сервер «Созвона»

Приложение по умолчанию подключается к общему серверу, но может работать и со своим.
Это нужно, когда переписка и звонки не должны зависеть от чужого администрирования —
например, для семьи, друзей или небольшой команды.

## Что нужно

- VPS с Ubuntu 22.04 или 24.04, от 2 ГБ памяти и 20 ГБ диска (на 1 ГБ скрипт добавит подкачку, но звонкам будет тесно).
- Открытые порты: 80 и 443 (TCP), 3478 (TCP и UDP), 5349 (TCP и UDP).
- Домен — необязательно. Без домена сервер возьмёт адрес вида `135-106-226-12.sslip.io`.

## Установка

Одной командой на чистом сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/IlyaDasler/sozvon/main/deploy/vps/setup.sh | sudo bash
```

С параметрами:

```bash
sudo DOMAIN=chat.example.com INVITE_CODE=моя-семья bash deploy/vps/setup.sh
```

Что поставится:

| Компонент | Зачем |
|---|---|
| Node.js и сам сервер | сообщения, комнаты, аккаунты, API |
| LiveKit | звонки и демонстрация экрана (медиасервер) |
| coturn | связь напрямую, когда между людьми NAT |
| Caddy | HTTPS с автоматическим сертификатом Let's Encrypt |
| systemd-службы | автозапуск и перезапуск при падении |
| Ежедневная копия | база в `/var/backups/sozvon`, при настройке — выгрузка в S3 |

Скрипт можно запускать повторно: он обновляет код, но сохраняет базу, секреты и код приглашения.

## Куда подключать клиент

1. На экране входа нажмите **«Свой сервер»**.
2. Введите адрес: `https://chat.example.com` (или IP с портом: `http://203.0.113.10:3000`).
3. Войдите или зарегистрируйтесь — аккаунты живут на выбранном сервере.

Сменить сервер позже: **Настройки → Сервер → «Сменить сервер»**. После смены нужно войти заново:
аккаунты на разных серверах не связаны.

Адрес сохраняется в настройках приложения и подставляется при следующем запуске.

## Порты и доступ

- 80/443 — сайт, API, WebSocket и LiveKit (через Caddy).
- 3478/5349 — TURN, нужен для звонков между людьми за разными NAT.
- 3000, 7880 — слушают только localhost, наружу их не открывайте.

## Резервные копии

Локально: `/var/backups/sozvon`, ежедневно в 04:00 (systemd-таймер `sozvon-backup.timer`).
Выгрузка в объектное хранилище: таймер `sozvon-offsite.timer` в 04:30. Чтобы включить,
заполните `/root/.config/rclone/rclone.conf` (пример — в `deploy/vps/backup-offsite.sh`).

## Обновление сервера

Повторный запуск того же скрипта:

```bash
curl -fsSL https://raw.githubusercontent.com/IlyaDasler/sozvon/main/deploy/vps/setup.sh | sudo bash
```

Или из клона репозитория: `sudo bash deploy/vps/setup.sh`.

## Шифрование

Личные сообщения и переписка в комнатах шифруются **на устройстве** (ECDH P-256 + AES-GCM):
сервер хранит только шифр и не может прочитать содержимое — ни при работе, ни по запросу.
Ключ создаётся на первом устройстве и переносится на другие 16-символьным кодом
(Настройки → Сквозное шифрование → «Перенести ключ на другое устройство»).

Что сервер всё же видит: имена пользователей, названия каналов и комнат, время сообщений,
размер вложений. Метаданные — не содержимое. Если и это важно скрыть, ставьте свой сервер.

## Если что-то не работает

```bash
systemctl status sozvon livekit caddy coturn
journalctl -u sozvon -n 100 --no-pager
```

Проверка снаружи: `curl -I https://ваш-домен/api/health` должен вернуть 200.
