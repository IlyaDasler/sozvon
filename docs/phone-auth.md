# Регистрация по телефону через Telegram

Бесплатная альтернатива SMS: телефон и пароль, а владение номером подтверждает
Telegram Contact Share. SMS не отправляются.

## Что нужно

1. Создать бота у [@BotFather](https://t.me/BotFather): `/newbot`.
2. В `/setjoingroups` выбрать бота **кнопкой** и нажать `Disable` (необязательно,
   но бот не должен попадать в группы).
3. Положить токен в окружение сервера:

```text
TELEGRAM_BOT_TOKEN=123456789:AA...
```

Токен не хранится в git и не попадает в клиент.

Серверу нужен исходящий доступ к `https://api.telegram.org`; публичный домен
и webhook не нужны — используется long polling.

## Поток

1. Пользователь в приложении вводит телефон, логин, имя и пароль.
2. Сервер сохраняет **только HMAC телефона**, хеш пароля и одноразовую заявку на
   10 минут.
3. Клиент открывает `https://t.me/<bot>?start=<token>`.
4. Бот показывает кнопку «Отправить номер».
5. Пользователь нажимает её; Telegram присылает номер.
6. Бот проверяет `contact.user_id == from.id` и сравнивает HMAC номера с заявкой.
7. Клиент опрашивает статус и после подтверждения завершает регистрацию.
8. Ключ шифрования запечатывается паролем — как при обычной регистрации.

Повторный вход: **телефон + пароль**, без Telegram и SMS.

## Что хранится

```text
users.phone_hmac          HMAC-SHA256(E.164, secret)
phone_signups             заявка: phone_hmac, password_hash, username,
                          token_hash, poll_hash, chat_id на 10 минут
```

Сам номер, Telegram user id и код не сохраняются после завершения заявки.
Номер не показывается другим пользователям; для друзей остаётся логин.

## Ограничения

- Пользователю нужен Telegram.
- Пользователи без Telegram входят по логину/паролю, Яндексом или email.
- Если Telegram недоступен, регистрация по телефону временно не работает.
- Смена номера требует нового подтверждения и пароля.

## Переменные

```text
TELEGRAM_BOT_TOKEN   токен BotFather
TELEGRAM_API_BASE    необязательно, для тестов (по умолчанию https://api.telegram.org)
```
