# Созвон 3.6.5 — усиление безопасности

- Разрешения Electron выдаются только доверенным страницам приложения, а не произвольному origin.
- Если системное хранилище не может зашифровать сессию, она больше не сохраняется открытым текстом.
- Смена публичного ключа ограничена по частоте; после неё остальные сессии завершаются.
- Добавлены защитные HTTP-заголовки.
- Новые резервные копии ключа используют PBKDF2 600 000 итераций; старые копии продолжают открываться по сохранённому числу итераций.
- Обновлена криптографическая зависимость Go.
- Добавлены тесты на origin разрешений и отказ от небезопасного хранения секретов.
