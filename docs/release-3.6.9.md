# Созвон 3.6.9 — журнал смены ключей

- Сервер хранит историю публичных ключей аккаунта (кто и когда менял).
- Клиент при смене ключа собеседника показывает число записей в журнале и предлагает сверить код.
- Это обнаружение смены, а не криптографическая прозрачность: сервер-оператор всё ещё может переписать свою базу.
