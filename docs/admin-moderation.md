# Глобальная модерация 3.9

## Bootstrap

Super admin задаётся только серверной переменной, не через клиент:

```env
SUPER_ADMIN_USER_IDS=9,20
```

ID проверяются при старте и получают роль `super_admin`. Пароли и TOTP в
конфигурации не хранятся.

## Вход

- `/admin` — отдельная панель;
- логин и пароль аккаунта;
- если в аккаунте включён TOTP, он обязателен;
- сессия админки живёт 12 часов, не пересекается с обычной сессией приложения;
- все изменения требуют CSRF-токен;
- после перезагрузки страницы CSRF-токен ротируется.

## Что доступно

- пользователи: ID, логин, имя, регистрация, последний вход, сессия, статус,
  роль, жалобы; email только маскированный, телефон — только флаг;
- каналы: все hubs/rooms, владелец, участники, приватность, последняя активность;
- жалобы и апелляции;
- аудит.

Сообщения, вложения, ключи, сырые email/телефон/IP не отдаются.

## Действия

- модератор может заморозить аккаунт;
- бессрочный бан и удаление канала модератор только запрашивает;
- подтверждает super admin, кроме собственной заявки;
- super admin может выполнить действие напрямую;
- разбан — забанивший или super admin;
- разбан создаёт пустой аккаунт без истории и ключей;
- баны и удаления необратимы на сервере; копии у собеседников и в старых
  бэкапах не отзываются.

## Blacklist

Хранятся только HMAC:

- username;
- email;
- phone_hmac;
- OAuth provider id;
- device key hash;
- IP hash.

Сырые значения не сохраняются. Blacklist блокирует регистрацию, вход по телефону,
OAuth и обычный вход.

## Приватность каналов

- `public` — по умолчанию;
- `hidden` — только по приглашению/прямой ссылке;
- настройка доступна владельцу канала/комнаты и администратору.

## Релиз

Изменения не выпускаются без отдельного подтверждения. В патчноуте будет только
«Обновление безопасности приложения».
