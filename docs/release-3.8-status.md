# Созвон 3.8 — статус

## Прод

- Версия: 3.8.0.
- Релиз выпущен 16.11.2026.
- CI тега v3.8.0: e2e, multi-device, Windows и macOS — success.
- Внешний key-history witness опубликован в GitHub.

## Готово

- Utility-процесс для privateJwk.
- X3DH prekey API с подписью сервера.
- v2-личные сообщения: X3DH + ratchet.
- DH-ротация ключей.
- Зашифрованный кэш v2-истории; reload проверен e2e.
- v2 отправляет только устройство-владелец prekey.
- CSP/HSTS.
- Шифрованные бэкапы SQLite.
- Подписи key history.
- Dual-format ключей.
- Проверка установщика/TOCTOU.
- Проверка URL превью.
- Бесплатная регистрация/привязка телефона через Telegram Contact Share.

## Проверки

```text
e2e-e2ee — все проверки
e2e-x3dh — X3DH + v2
e2e-multidevice — два устройства, оба читают и отправляют
ratchet-dh — 4/4
x3dh — 2/2
e2ee-v2 — 2/2
npm test — зелёные
go test ./... — зелёные
```

## Не готово

- Multi-device v3 проверен отдельным e2e: два процесса, два device key, оба читают и отправляют.
- Комнаты v4: per-message ключи, копии на устройства, гибридная история (v1 читается, v4 до входа — нет).
- История v1 остаётся читаемой.
- Key transparency: подписанная hash-chain + внешний GitHub-снапшот.

## Риск выпуска

Если выпустить 3.8 сейчас:
- на новом устройстве часть текущей v2-переписки будет недоступна;
- комнаты не получат forward secrecy;
- старые и новые сообщения будут в разных схемах.

Поэтому релиз 3.8 не выпускается.
