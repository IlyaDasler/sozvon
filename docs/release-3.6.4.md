# Созвон 3.6.4 — защита смены ключа

- Смена уже опубликованного ключа шифрования требует пароль аккаунта; одной украденной сессии недостаточно.
- Ключ с текущего устройства разрешено вернуть на сервер после проверки пароля — без кода переноса.
- Добавлен серверный тест: без пароля ключ не меняется, с неверным паролем — тоже.
