# Созвон 3.3.1 — черновик

**Не выпускать до просмотра пользователем.** Прод остаётся на 3.3.0.

## Что правим

- окно выбора камеры/экрана: top-layer `<dialog>`, непрозрачная карточка, видимый список источников;
- уведомления растут из колокольчика, а не с правого края окна;
- иконка приложения выровнена по шапке канала;
- кнопки звонка принудительно круглые;
- громкость трансляции доступна в контекстном меню самой трансляции;
- ПКМ по трансляции показывает её опции, а не общий шумодав;
- шумодав: сильнее RNNoise, браузерная изоляция голоса и гейт остаточного фона;
- убран лишний number-stepper у шумоподавления — остаётся ползунок с подписями;
- устройство в настройках подписывается актуальной версией приложения, а не версией старой сессии;
- фон стекла: лесной пейзаж с несколькими планами, широкими кронами, папоротниками и водой; без совы на дереве.

## Проверки перед показом

- `e2e-layout`, `e2e-look`, `e2e-threads`, `e2e-room`;
- unit-тесты клиента и Node-сервера;

- скриншоты в `_backup/ui33`.
