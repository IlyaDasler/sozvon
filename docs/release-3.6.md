# Созвон 3.6.0 — подготовка релиза

Статус: **подготовлено, не опубликовано**. Тег и выкладка — только после отдельного подтверждения и зелёного macOS e2e.

## Что нового для пользователя

- Регистрация по телефону с подтверждением через Telegram Contact Share.
- Одно поле «Почта или телефон» при входе и регистрации.
- Понятные ошибки, если почта или номер уже привязаны к аккаунту.
- Показ пароля во всех полях ввода.
- Восстановление пароля:
  - почта — код на почту;
  - телефон — подтверждение номера в Telegram.
- Удаление аккаунта с 30-дневным сроком восстановления и таймером.
- После истечения срока профиль и история удаляются окончательно.
- При привязке почты/телефона к аккаунту без пароля нужно создать пароль — он защищает резервную копию ключа.
- Telegram при регистрации открывается через установленное приложение, иначе через веб-версию.
