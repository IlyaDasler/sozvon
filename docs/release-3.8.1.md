# Созвон 3.8.1

Исправлено восстановление ключа шифрования после обновления.

- В 3.8.0 utility-процесс не находил криптомодули внутри установленного пакета.
- Из-за этого приложение считало локальный ключ недоступным и предлагало восстановление по паролю.
- Ключ при этом не терялся: он оставался в локальном хранилище.
- В 3.8.1 криптомодули включены в установочный пакет; ключ загружается сразу.

## Вход и телефон

- Вход по номеру телефона и паролю — с 3.7.1.
- Регистрация по номеру телефона и паролю.
- Привязка номера к существующей учётке через Telegram — с 3.7.1.
- Подтверждение через Telegram Contact Share, без SMS.
- Если Telegram Desktop установлен, открывается он; если нет — веб-версия.
- Microsoft Store для Telegram не используется.
- Номер хранится на сервере только как HMAC.
