# Code signing policy

Free code signing provided by [SignPath.io](https://signpath.io), certificate by [SignPath Foundation](https://signpath.org).

## What is signed

Windows installers (`Sozvon-Setup-*.exe`) published on the [Releases](https://github.com/IlyaDasler/sozvon/releases) page. They are built by [GitHub Actions](../.github/workflows/build.yml) from this repository. Every release is approved by hand before signing.

## Team

| Role | Members |
| --- | --- |
| Committers and reviewers | [IlyaDasler](https://github.com/IlyaDasler), [Finjust](https://github.com/Finjust) |
| Approvers | [IlyaDasler](https://github.com/IlyaDasler) |

Changes from anyone else are reviewed by a team member before they are merged. All team members use multi-factor authentication for GitHub and SignPath.

## Privacy

See the [privacy policy](privacy.md). The program connects only to the systems listed there.
