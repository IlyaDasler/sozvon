## Отчёт для пользователей

### Исправление багов

Исправлены индикатор речи, масштаб и громкость трансляции, отступы участников,
уведомления, сворачивание настроек, выбор экрана и камеры, анимация вкладок и
синхронизация голосового канала между устройствами.

### Новое

«Жидкое стекло» стало темой по умолчанию. Раздел «Оформление» разделён на
классические и новые темы. В обсуждениях можно отмечать людей через `@`.
Фон стекла — место обитания совы: рассвет, день, закат и ночь меняются по
часовому поясу пользователя и часам сервера. Звуки приложения стали мягче,
входящий звонок звучит спокойнее.
