# Samsung: матрица экранов

Размеры — CSS px (dp), не физические пиксели. Реальные устройства Samsung
имеют несколько режимов плотности, поэтому проверяем CSS-диапазоны.

| Устройство | CSS viewport | Режим |
|---|---|---|
| Galaxy A / маленький | 320×568 | compact |
| Galaxy S23 | 360×780 | compact |
| Galaxy S24 Ultra | 480×1040 | compact |
| Fold 5 снаружи | 344×882 | compact |
| Fold 5 внутри | 673×841 | Workspace |
| Fold 6 внутри | 690×829 | Workspace |
| Flip 5 раскрыт | 396×915 | compact, высокий телефон |
| Flip 5 обложка | 328×360 | cover/glance |

## Обложка Flip

PWA не получает модель устройства. Обложка определяется по маленькому
почти квадратному viewport: часы, дата, число событий и кнопка
«Открыть приложение». Это glance-экран, а не полноценный интерфейс;
для точного определения нужен нативный DevicePosture.

## Проверка

`e2e-mobile-samsung` проходит все восемь размеров, проверяет отсутствие
горизонтального скролла, правильный rail/nav и включение cover-режима.
