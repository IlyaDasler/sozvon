# Свой сервер Созвона

Как поднять сервер для своей компании: на домашнем ПК или на VPS, а также почта для кодов и вход через Яндекс. Как работает само приложение — в [README](../README.md).

## Сервер на домашнем ПК с Windows

Подходит, если провайдер даёт «белый» IP (внешний IP в настройках роутера совпадает с тем, что показывает, например, 2ip.ru). Для 10–15 человек хватит любого ПК.

1. Установите [Node.js](https://nodejs.org) 22.13 или новее.
2. Скачайте проект и запустите установку:
   ```powershell
   git clone https://github.com/IlyaDasler/sozvon.git
   cd sozvon
   powershell -ExecutionPolicy Bypass -File deploy\windows\install-server.ps1
   ```
   Скрипт скопирует сервер в `%LOCALAPPDATA%\SozvonServer`, включит встроенный TURN-сервер, придумает код приглашения и настроит запуск в фоне при входе в Windows. В конце он покажет адрес для друзей и код.
3. Когда Windows спросит про доступ к сети для Node.js, разрешите доступ в частных и общественных сетях.
4. В роутере пробросьте порты на ваш ПК: `3000/TCP`, `3478/UDP`, `49160-49200/UDP`. Там же закрепите за ПК постоянный локальный IP.
5. Друзья ставят приложение, указывают адрес `http://<ваш IP>:3000` и при регистрации вводят код приглашения.

Журнал сервера лежит в `%LOCALAPPDATA%\SozvonServer\logs\server.log`, база — в `data`. Отключить сервер: `deploy\windows\uninstall-server.ps1`.

Встроенный TURN не пересылает трафик на адреса домашней сети, поэтому через него нельзя добраться до других устройств у вас дома.

**Если на ПК включён VPN.** Сервер работает и с включённым VPN: Windows отвечает на входящие подключения через тот же адаптер (Wi‑Fi или кабель), через который они пришли, а не через туннель. Важно одно: друзьям нужен ваш настоящий домашний IP, а не адрес VPN-сервера. Скрипт установки определяет его сам, отправляя запрос мимо VPN. Сайты вроде 2ip.ru при включённом VPN покажут адрес VPN, им верить нельзя. Если IP сменился, просто запустите скрипт ещё раз. На своём ПК подключайтесь к серверу по адресу `http://localhost:3000`.

## Регистрация по почте и вход через Яндекс

Аккаунт создаётся по своей почте: почта, имя и пароль, а на почту приходит шестизначный код, который нужно ввести. Войти потом можно по почте или по логину. Почта — такой же способ входа, как Яндекс: к уже созданному профилю её привязывают в **Настройках → Способы входа** (тоже по коду из письма) и там же отвязывают. На экране входа есть «Забыли пароль?» — новый пароль задаётся по коду из письма. Старые профили с логином и паролем работают как раньше.

Письма отправляет почтовый ящик, указанный на сервере (SMTP). Пока его нет, регистрация по почте и коды не работают — приложение об этом скажет. Ящик для отправки — например, отдельная почта на Яндексе:

1. Заведите ящик (например, `sozvon.noreply@yandex.ru`) и в настройках почты включите доступ почтовым программам (**Все настройки → Почтовые программы**, протокол IMAP).
2. В [Яндекс ID → Безопасность → Пароли приложений](https://id.yandex.ru/security/app-passwords) создайте пароль приложения для почты.
3. Впишите на сервере:

   ```
   SMTP_HOST=smtp.yandex.ru
   SMTP_PORT=465
   SMTP_USER=sozvon.noreply@yandex.ru
   SMTP_PASS=пароль-приложения
   ```

Также можно войти через Яндекс: приложение откроет страницу входа в своём окне, а после подтверждения окно закроется само. К уже созданному профилю Яндекс привязывается в **Настройках → Вход через сервисы**. Если на сервере включён код приглашения, он нужен и для первой регистрации. Кнопка «Войти через Яндекс» появляется, только если на сервере указаны ключи:

1. Откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) и войдите в Яндекс ID.
2. Название сервиса: `Созвон`, иконка — по желанию.
3. Платформа: **Веб-сервисы**, Redirect URI: `http://localhost:47615/callback`.
4. В разделе доступов отметьте **Доступ к адресу электронной почты** (`login:email`) и **Доступ к логину, имени и фамилии, полу** (`login:info`).
5. Нажмите **Создать приложение** и скопируйте **ClientID** и **Client secret**.

### Куда вписать ключи и почтовый ящик

- **Сервер на VPS:** в `/etc/sozvon.env` (`YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `SMTP_*`), затем `systemctl restart sozvon`.
- **Сервер на домашнем ПК:** откройте в Блокноте `%LOCALAPPDATA%\SozvonServer\oauth.cmd`, вставьте значения после знаков `=` и запустите `deploy\windows\install-server.ps1` ещё раз — он перезапустит сервер.
- **Для разработки:** задайте те же переменные окружения.

Порт `47615` открывается только на время входа через Яндекс и только на этом компьютере. Пробрасывать его в роутере не нужно.

## Свой сервер на VPS

Подойдёт любой VPS с Linux (Timeweb Cloud, Selectel, REG.RU, Beget и т.п.), хватит 1 ядра и 1 ГБ памяти.

1. Установите Docker: `curl -fsSL https://get.docker.com | sh`
2. Скачайте проект и настройте:
   ```bash
   git clone https://github.com/IlyaDasler/sozvon.git
   cd sozvon/deploy
   cp .env.example .env
   nano .env        # впишите PUBLIC_IP и TURN_SECRET
   docker compose up -d
   ```
3. Откройте порты в файрволе: `3000/tcp`, `3478/tcp+udp`, `49160-49200/udp`.
4. В приложении укажите адрес `http://<IP-сервера>:3000`.

**HTTPS (рекомендуется).** Без него пароли идут по сети в открытом виде. Если есть домен, направьте его на IP сервера, впишите в `.env` строку `DOMAIN=ваш.домен` и запустите `docker compose --profile https up -d`. Сертификат выпустится автоматически, а адрес в приложении будет `https://ваш.домен`. Заодно появится веб-версия: друзья смогут зайти из браузера.

Данные (база и ключ подписи токенов) лежат в Docker-томе `sozvon-data`.
