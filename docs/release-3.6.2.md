# Созвон 3.6.2 — автоматическое восстановление ключа

- Ключ шифрования сохраняется отдельным файлом профиля и переживает очистку localStorage при обновлении.
- Если локальный ключ всё же потерян, вместо кода переноса запрашивается пароль аккаунта — серверная копия открывается автоматически.
- Ручные коды переноса и кнопка «Перенести ключ на другое устройство» удалены из интерфейса.
- Добавлены e2e-сценарии: восстановление по паролю на новом устройстве и восстановление ключа при пустом локальном кэше.
