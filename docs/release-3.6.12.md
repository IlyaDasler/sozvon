# Созвон 3.6.12 — восстановление старой копии ключа

- Сервер хранит историю прежних паролей и принимает их для чтения резервной копии.
- Для копий, созданных до появления истории, разрешён переходный режим: сервер отдаёт только шифртекст, открыть его можно старым паролем.
- В окне восстановления подсказка: если пароль менялся, введите прежний.
- Ошибка «копия найдена, но не открылась» теперь прямо подсказывает попробовать прежний пароль.
