# Созвон 3.6.13 — возврат локального ключа

- Исправлен конфликт IPC-канала `identity:load`: новый main-сервис и старое vault-хранилище использовали одно имя, из-за чего старый локальный ключ не мигрировал.

- Если ключ уже лежит на этом компьютере, он загрузится автоматически без пароля.
- Сохранены исправления 3.6.12: окно восстановления поверх настроек, текущие/прежние пароли, Argon2id.
