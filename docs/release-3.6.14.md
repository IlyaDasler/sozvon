# Созвон 3.6.14 — критическое исправление загрузки ключа

- `registerIdentityVault()` снова вызывается в main-процессе. Без этого IPC-сервис ключа не был зарегистрирован, и старый локальный ключ не импортировался.
- Добавлен регрессионный тест, что main регистрирует identity-vault.
- После обновления ключ с этого компьютера должен загрузиться автоматически, без пароля.
- Включены исправления 3.6.12–3.6.13: окно поверх настроек, текущий/прежний пароль, Argon2id, каналы identity-vault.
