# Мобильный release gate

Обновлено после матрицы 320 / 360 / 390 / 412 / 844×390 / 344 / 396 / 673 / 935.

## Готово для внутренней PWA-беты

- установка PWA на Android;
- вход и регистрация;
- друзья, заявки, личные чаты;
- хабы, голосовые и текстовые комнаты;
- текстовая переписка и отправка сообщений;
- уведомления отдельным экраном;
- настройки и все 12 тем;
- нижняя навигация на телефоне;
- Workspace на раскрытом фолде;
- портретные обои на телефоне, широкие на фолде;
- жесты и долгие нажатия;
- одна внешняя рамка, без вложенных карточек;
- отсутствие ложного селекта хаба;
- отсутствие белой полоски активного хаба;
- матрица разрешений без горизонтального переполнения.

Проверки: `e2e-mobile`, `e2e-mobile-formfactors`, `e2e-mobile-matrix`, `e2e-mobile-frames`, `e2e-mobile-friends`, `e2e-mobile-utility`, `e2e-mobile-wallpapers`, `e2e-mobile-message`, `e2e-mobile-call`, `e2e-mobile-settings`, `npm test`.

## Не готово для публичного релиза

### Блокеры P0

- нет APK/нативной оболочки;
- нет фоновых push и фоновых звонков;
- нет FCM/foreground service;
- нет экрана обложки флипа: PWA не отличает его от маленького телефона;
- голосовой звонок двух устройств и панель звонка проверены; камера, демонстрация экрана и аудиофокус ещё нет;
- нет физического теста на Android-фолдах и флипах;
- CI после последних коммитов не подтверждён (потеряна авторизация GitHub CLI).

### Функции, требующие мобильного прохода

- поиск;
- файлы, изображения, видео и вложения;
- реакции и действия с сообщениями;
- настройки комнаты и канала, роли, приглашения;
- профиль и статусы;
- история звонков;
- настройки уведомлений.

## Правило выпуска

Пока P0-блокеры не закрыты, мобильная версия остаётся **PWA-бетой**. Публичный APK и обновление мобильного приложения не выпускаются.
