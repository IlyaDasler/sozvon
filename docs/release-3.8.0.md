# Созвон 3.8 — черновик

## Безопасность

- После скачивания обновления клиент проверяет sha512 установщика по подписанному манифесту; установка без проверки блокируется.
- Автоустановка при выходе отключена: непроверенный установщик не может стартовать в обход проверки.
- Записи истории ключей подписываются Ed25519-ключом; клиент проверяет подпись вместе с hash-chain.
- Добавлены HSTS и Content-Security-Policy для веб-версии и API.
- Ежедневные резервные копии SQLite шифруются GPG AES-256; ключ хранится отдельно от сервера.
- Новые копии ключа содержат Argon2id и PBKDF2-совместимую часть; старые клиенты могут восстановить ключ, но не могут перезаписать новую копию.
- Убран js-yaml из рантайма; npm audit — 0 уязвимостей.
- Приватный ключ E2EE вынесен в отдельный Electron utility-процесс; main не хранит его постоянно, открытие ключей ограничено 240 раз в минуту.
- Ссылки и превью из сообщений проверяются по схеме http/https, без javascript:/file:/data:; превью-картинки вставляются без CSS url().

## Телефон

- Регистрация по номеру телефона через Telegram Contact Share.
- Привязка номера к существующей учётке тем же способом.
- Без SMS, номер хранится как HMAC.
