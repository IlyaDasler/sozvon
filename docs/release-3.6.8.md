# Созвон 3.6.8 — ключ вне renderer и Argon2id

- Приватный ключ E2EE перенесён в main-процесс. Renderer получает только публичный ключ и узкие операции open/wrap/unwrap; privateJwk больше не хранится в JS-странице.
- Старые ключи из localStorage и старого файла профиля импортируются один раз и удаляются.
- Новые резервные копии ключа используют Argon2id (64 МБ, 3 итерации, 1 поток); старые PBKDF2-копии продолжают открываться.
- Добавлена миграция и тесты восстановления на новом устройстве.
