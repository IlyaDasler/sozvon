# Созвон 3.0 — дизайн-система

Документ описывает структуру дизайн-системы приложения: фундамент, компоненты, паттерны
экранов, движение и доступность. Любая правка интерфейса должна опираться на этот документ,
а не на отдельные значения «на глаз».

## 1. Принципы

1. **Один материал на один смысл.** Стекло — для того, через что действуют (кнопки, меню, окна,
   тосты). Плоская заливка — для того, что несёт значение (поля, чекбоксы, радио, свитчер).
   Акцент и опасность — сплошные: цвет и есть сообщение.
2. **Один ритм.** Четыре длительности и две кривые на весь интерфейс. Никаких «0.14 у плитки,
   0.2 у кнопки».
3. **Геометрия проверяется, а не обсуждается.** Всё, что можно измерить, измеряется тестом:
   центровка иконок, высоты шапок, отсутствие переполнений на 480/760/1280.
4. **Тема — это токены, а не набор CSS-хаков.** Все цвета, радиусы, тени и шрифты берутся
   из переменных.
5. **Без скевоморфизма.** Глянцевые градиенты «сверху блеск, снизу тень» запрещены; допускается
   кромка-блик 1 px и мягкая тень.

## 2. Фундамент (токены)

Источник значений: `client/renderer/tokens.css` (подключён первым), темы — `themes.css`,
стекло — `glass.css` + `glass-system.css`.

### 2.1 Цвет

| Токен | Назначение |
|---|---|
| `--bg-deep` … `--bg-5` | пять уровней поверхности |
| `--line`, `--line-strong` | волосяные границы |
| `--text`, `--text-2`, `--muted` | текст: основной, вторичный, подписи |
| `--accent`, `--accent-2`, `--accent-hover` | акцент темы (может приходить из ОС) |
| `--on-accent` | текст на акценте |
| `--ok`, `--warn`, `--danger` | состояния |
| `--lq-tint`, `--lq-tint-deep`, `--lq-control`, `--lq-control-rim` | материал стекла |
| `--lq-rim-hi`, `--lq-rim-lo` | блик и контр-блик кромки |
| `--lq-accent`, `--lq-danger`, `--lq-danger-text`, `--lq-scrim` | стеклянная тема |

### 2.4 Движение

| Токен | Значение | Где |
|---|---|---|
| `--dur-1` … `--dur-4` | 120 / 180 / 240 / 320 мс | все переходы |
| `--ease-out` | `cubic-bezier(.22,1,.36,1)` | появление, наведение |
| `--ease-spring` | `cubic-bezier(.22,1.12,.36,1)` | плитки, бегунок, подложка вкладок |

Правила: подложка вкладок — один морфинг 320 мс (без двухфазного растяжения); «вспухание»
канала — 280 мс, амплитуда 0.94 → 1.02 → 1; окна — 190 мс; меню — 140 мс.
Всё гасится при `prefers-reduced-motion`, прозрачность — при `prefers-reduced-transparency`.

### 2.5 Материал стекла

| Слой | Что делает | Где |
|---|---|---|
| Аврора на фоне | четыре медленно плывущих пятна, чтобы стеклу было что преломлять | `glass-liquid.css`, `.lg-aurora` |
| Тинт + размытие | `backdrop-filter: blur() saturate() brightness()` на панелях и окнах | `glass.css`, `glass-system.css` |
| Изогнутая кромка | светлая кайма сверху, тёмная снизу, conic-кольцо по периметру | `glass-liquid.css` |
| Блик | медленная полоса света, едет `transform` (композитно, без `mix-blend-mode`) | `glass-liquid.css` |
| Глубина | близкая контактная и дальняя объёмная тени | `--lg-shadow-near/far` |

**Рефракция.** Chromium (и Electron) принимает `backdrop-filter: url(#filter)` — проверено
контрольным опытом, поэтому линза настоящая: `glass-lens.js` строит карту смещения на canvas
(SDF скруглённого прямоугольника → нормали), кладёт PNG в `feImage`, а `feDisplacementMap`
смещает фон под кромкой. Слой линзы — под содержимым (`z-index: -1`), поэтому текст остаётся
резким. Сейчас линза включена для плавающих слоёв: модалки, меню, поповеры, карточка профиля,
тосты. Панели и кнопки — следующий шаг, их больше и они крупнее.

Если фильтр недоступен или включён `prefers-reduced-transparency`, остаётся световой вариант:
кромка и блик.

## 4. Паттерны экранов

1. **Каркас окна:** полоса заголовка 32 px, рейл 72 px, сайдбар 248 px (настраивается),
   контент, панель участников 280 px (на узком окне — Drawer поверх чата).
2. **Узкое окно (< 760 px):** одна колонка — рейл и сайдбар скрыты, чат на всю ширину.
3. **Голосовая комната:** сцена → полоса плиток → панель управления → список участников.
4. **Чат:** шапка 52 px, лента с группировкой (< 5 мин), разделитель дня, композер — плоская полоса,
   ширина чтения 78ch.
5. **Настройки:** навигация 190 px, панели-блоки, шапка 52 px с линией.
6. **Каналы:** рейл с фото в скруглённых квадратах, список комнат по секциям, карточка профиля.

## 5. Доступность

- фокус: кольцо `0 0 0 3px accent/38%`;
- `prefers-reduced-motion` — анимации до 1 мс;
- `prefers-reduced-transparency` — сплошной фон вместо стекла;
- контраст текста на стекле: тинт держит легибельность, а не только блик;
- цели нажатия: не меньше 28×28 px (иконки), 40 px (кнопки), 44 px (круглые кнопки звонка).

## 7. Как менять дизайн-систему

1. Новое значение — сначала токен, потом использование.
2. Новый компонент — строка в матрице (таблица раздела 3) и пример в `design/ui-kit.html`.
3. Любая геометрическая правка — проверка в `e2e-layout` (центровка, высоты, переполнения).
4. Скевоморфизм и «на глаз» значения в компонентах запрещены.
