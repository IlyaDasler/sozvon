# Созвон

Голосовые звонки, видео и чат с друзьями — для игр и не только. Работает в России без VPN.

![Созвон](docs/screenshot.png)

Скачать: [Releases](https://github.com/IlyaDasler/sozvon/releases) · [Code signing policy](docs/code-signing.md) · [Конфиденциальность](docs/privacy.md)

## Как это работает

- **Друзья.** Добавляете друга по логину — ему приходит заявка. Приняли — можно писать и звонить.
- **Звонки.** Голос и видео идут напрямую между компьютерами, сервер только помогает им найти друг друга. В звонок можно позвать ещё друзей — до 10 человек.
- **Каналы.** Свой «сервер» для компании: внутри голосовые и текстовые комнаты, роли и права. Друзей приглашают в канал целиком.
- **Сквозное шифрование.** Звук и видео шифруются ключами, которые создаются на ваших компьютерах, — сервер их не знает. В разговоре показан код из смайликов и цифр: если у всех он одинаковый, разговор слышат только участники. Личная переписка и чаты комнат тоже шифруются на устройстве: сервер хранит только шифр, а ключ переносится на новый компьютер одноразовым кодом.
- **Трансляция экрана** в 1440p 60 кадров/с, 1080p 60 или 720p 90 — со звуком игры, но без ваших собеседников в нём.
- **Чат** с разметкой, файлами, картинками, смайликами и превью ссылок.

## Приватность

Переписка в личных чатах и в комнатах шифруется **на ваших устройствах** (ECDH P-256 + AES-GCM).
Сервер хранит только шифр и не может прочитать содержимое — ни при работе, ни по запросу:
ключ создаётся на устройстве и переносится на другое одноразовым кодом. Звонки тоже шифруются,
а код из смайликов и цифр в разговоре показывает, что у всех участников один и тот же ключ.

Что сервер видит и без ключа: имена пользователей, названия каналов и комнат, время сообщений,
размер вложений. Это метаданные, не содержимое.

## Свой сервер

Код открыт целиком — и клиент, и сервер (MIT). Приложение по умолчанию подключается к общему
серверу, но вы можете поставить свой: для семьи, друзей или команды, без чужого администрирования.

- **Поднять сервер:** одна команда на Ubuntu VPS — [`deploy/vps/setup.sh`](deploy/vps/setup.sh)
  (ставит Node.js, LiveKit, coturn, Caddy и systemd-службы). Подробная инструкция:
  [docs/self-hosting.md](docs/self-hosting.md).
- **Подключить приложение:** на экране входа нажмите «Свой сервер» и введите адрес.
  Выбор сохраняется; сменить позже — Настройки → Сервер.

## Установка

Скачайте `Sozvon-Setup-x.y.z.exe` на странице [Releases](../../releases) и запустите — он ставится для текущего пользователя без прав администратора. Дальше приложение обновляется само.

> Установщик не подписан сертификатом, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

### macOS

На странице [Releases](../../releases) возьмите `Sozvon-<версия>-arm64.dmg` (Apple Silicon, M1–M4) или `Sozvon-<версия>-x64.dmg` (Intel), откройте и перетащите «Созвон» в «Программы».

> **Запускайте только из «Программ».** Если открыть приложение прямо из образа, macOS запускает его из временной папки: обновления не смогут установиться, а после перезагрузки ярлык перестанет работать. Приложение предупредит об этом при первом запуске из образа.

> Если загрузка оборвалась, macOS напишет «образ повреждён». Проверить файл до установки можно по контрольной сумме из релиза (`SHA256SUMS-mac.txt`): `shasum -a 256 -c SHA256SUMS-mac.txt` в папке с загруженными файлами.

> Сборка для macOS пока не подписана сертификатом Apple, поэтому при первом запуске система скажет, что разработчик не проверен. Нажмите по приложению **правой кнопкой → «Открыть» → «Открыть»** (один раз, дальше запускается обычно).
>
> Если вместо этого macOS пишет «приложение повреждено, переместите в Корзину» — это про подпись, а не про файл. Откройте Терминал и выполните:
>
> ```
> sudo xattr -cr /Applications/Sozvon.app
> sudo codesign --force --deep --sign - /Applications/Sozvon.app
> ```
>
> Автообновление на macOS работает, но без сертификата Apple у него есть цена: после каждого обновления система заново спросит доступ к микрофону, камере и экрану (разрешения привязаны к подписи). Звук при показе экрана передаётся в Windows и на macOS 14.2+ — система спросит разрешение «Запись звука системы»; на более старых macOS трансляция идёт без звука.
