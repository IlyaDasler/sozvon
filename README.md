# Созвон

Голосовые звонки и чат с друзьями — для игр и не только. Свой сервер, никаких зарубежных сервисов: работает в России без VPN.

![Звонок в приложении](docs/screenshot.png)

**Что умеет:**

- регистрация по своей почте с кодом подтверждения из письма, вход по почте или логину, «Забыли пароль?», вход через Яндекс; почту и Яндекс можно привязать к профилю в настройках; профиль (имя, цвет аватара и баннера, «О себе», смена пароля); адреса одного ящика Яндекса (@yandex.ru, @ya.ru, @yandex.com и другие, с точкой или дефисом в логине) считаются одной почтой;
- друзья через заявку: по логину отправляется заявка, её можно принять, отклонить или заблокировать отправителя; раздел «Друзья» со вкладками «В сети», «Все», «Входящие», «Отправленные» и «Заблокированные»; статус «в сети / не в сети»;
- личные сообщения с историей;
- разметка в чате: **жирный**, *курсив*, __подчёркнутый__, ~~зачёркнутый~~, `код` и блоки кода, ||спойлеры||, цитаты, списки и заголовки; Enter отправляет, Shift+Enter — новая строка;
- ссылки в сообщениях кликабельны и открываются в браузере; под ссылкой — превью страницы (заголовок, описание, картинка), его можно убрать крестиком до отправки, чтобы ушла только ссылка;
- картинки, видео, звук и любые файлы в чате (до 10 штук по 25 МБ): кнопкой «+», перетаскиванием или вставкой из буфера; картинки открываются крупно, файлы скачиваются;
- смайлики: панель с разделами и недавними, сообщение из одного-трёх смайликов показывается крупно;
- темы оформления: «Созвон», «Полночь», «Светлая», «Лес», «Сумерки» — в **Настройках → Оформление**;
- **сходки** — свой «сервер» для своих: кнопка «Собрать сходку» внизу столбца слева, внутри — голосовые и текстовые комнаты; друзей зовут в сходку, и, вступив, они сразу попадают во все её комнаты (кроме тех, где их забанили); создатель может всё, а право «Управляет» (создавать и удалять комнаты, переименовывать, менять цвет и картинку, звать, выгонять и банить) он раздаёт сам; выйти из сходки можно в любой момент;
- столбец сходок слева: дом (друзья и личные сообщения) сверху, сходки — буквами или картинкой на своём цвете, полоска у открытой и у той, где есть непрочитанное, приглашения — пунктиром; **свой порядок и свои группы**: перетащите сходку на сходку — получится группа, её можно назвать, покрасить, свернуть и развернуть, а сходку — вытащить обратно; раскладка хранится только в вашем приложении, другие её не видят;
- окно сходки: в шапке — название и меню (позвать друзей, создать комнату, настройки, выйти или удалить), комнаты по разделам «Голосовые» и «Текстовые», справа — участники по ролям, «В сети» и «Не в сети»; список участников прячется кнопкой в шапке, и приложение это запоминает;
- карточка профиля по щелчку на аватарку или имя: баннер, статус, «О себе» с разметкой, дата регистрации, где человек сейчас в голосе, роль в комнате, общие сходки, личная заметка и кнопки «Написать» и «Позвонить»;
- голосовые и видеозвонки один на один (WebRTC, голос в Opus 64 кбит/с) с шумо- и эхоподавлением;
- комнаты в сходке: **голосовые** (общий разговор до 10 человек, камеры, демонстрация экрана и чат) и **текстовые** (только чат); щелчок по голосовой комнате сразу переносит в её голосовой канал, в списке видно, кто сейчас в голосе;
- роли и права в комнате: создатель может всё и заводит свои роли (название, цвет, набор прав: заходить в голос, говорить, камера и экран, писать, звать друзей, выгонять, банить, настраивать, администратор); права «всех без роли» тоже настраиваются; кикнуть на время (от минуты до недели — кикнутый остаётся в комнате, но только читает чат, а потом права роли возвращаются сами), отключить от голоса, убрать или забанить можно только того, у кого прав меньше;
- у каждой комнаты в списке — кнопки настроек и приглашения друзей, открываются, не заходя в комнату; настройки разбиты на «Обзор», «Роли и права», «Участники» и «Баны»;
- камера и демонстрация экрана включаются прямо во время разговора; экран — целиком или одно окно, в режиме «плавно» (720p, 60 к/с, для игр) или «чётко» (1080p, 30 к/с, для текста и фильмов); чужую трансляцию можно открыть на весь монитор, по желанию со звуком компьютера;
- проверка звука в настройках: полоска громкости микрофона, «Слушать себя» (микрофон сразу звучит в выбранных наушниках), запись 5 секунд с прослушиванием, проверка динамиков и камеры; во время разговора — пинг, потери пакетов и джиттер;
- шумоподавление включается и выключается одной кнопкой прямо в разговоре; микрофон и звук можно выключить себе кнопками или горячими клавишами;
- индикатор «говорит», своя громкость для каждого собеседника, выбор микрофона, наушников и камеры;
- глобальные горячие клавиши, которые работают прямо в игре: **Ctrl+Shift+M** — микрофон, **Ctrl+Shift+D** — звук;
- статусы профиля: активен, неактивен (включается и сам через 10 минут без мыши и клавиатуры), не беспокоить (без уведомлений на рабочем столе и звонков со звуком), невидимый (для друзей «не в сети»);
- уведомления: центр уведомлений (колокольчик) с сообщениями, пропущенными звонками, новыми друзьями и приглашениями в сходки; уведомления на рабочем столе со звуком, когда окно свёрнуто или спрятано в трей; настройки в разделе «Уведомления»;
- крестик окна прячет Созвон в трей Windows — голос, звонки и уведомления продолжают работать; щелчок по значку возвращает окно, а в его меню — «Открыть Созвон» и «Выйти»; повторный запуск ярлыка тоже показывает окно;
- фото профиля: загрузка в настройках, автоматическая обрезка до квадрата;
- обновления: при запуске приложение само смотрит релизы на GitHub и, если вышла новая версия, тихо подсвечивает это — плашка «Вышла версия X — Обновить» и точка на кнопке обновлений; «Обновить» показывает, что нового, и ставит обновление без лишних окон. Проверить вручную можно кнопкой рядом с колокольчиком, на экране входа и в настройках.

## Как это устроено

```
┌──────────────┐   HTTP + WebSocket   ┌──────────────────┐
│ Приложение   │ ───────────────────► │ Сервер (Node.js) │  аккаунты, друзья, сообщения,
│ для Windows  │ ◄─────────────────── │ + SQLite         │  «кто кому звонит»
└──────┬───────┘                      └──────────────────┘
       │  голос напрямую (WebRTC)     ┌──────────────────┐
       └────────────────────────────► │ TURN (coturn)    │  если напрямую не получилось
                                      └──────────────────┘
```

- `client/` — приложение на Electron (`main.js`, `preload.js`, интерфейс в `renderer/`).
- `server/` — сервер: REST API (`src/api.js`), сигналинг звонков и комнат (`src/signaling.js`, `src/voice.js`), база (`src/db.js`).

В голосовой комнате каждый участник соединён с каждым напрямую (сервер только пересылает сигналы WebRTC). Для компании до 6–8 человек этого хватает; если все одновременно включат камеры, нагрузка на интернет растёт с каждым участником.
- `deploy/` — Docker Compose для VPS: сервер + TURN + (по желанию) HTTPS через Caddy.

## Скачать и установить

Готовый установщик — на странице [Releases](../../releases). Скачайте `Sozvon-Setup-x.y.z.exe` и запустите: он ставит Созвон только для текущего пользователя, без вопросов и прав администратора, а запущенный Созвон закрывает сам. Если раньше Созвон стоял «для всех пользователей», приложение само поправит ярлыки и предложит удалить старую копию.

Со старыми версиями можно созваниваться: звонки работают с 1.3 и новее, общий голосовой канал — с 1.5 (в версиях до 1.5 комнат нет). Версии до 2.0 сходок не знают: они видят комнаты сходок, где человек уже есть, а комната, созданная в старой версии, попадает в сходку её создателя. Вступить в новую сходку по приглашению можно только из версии 2.0 и новее. При переходе на 2.0 комнаты не теряются: сервер собирает комнаты каждого создателя в «Сходку <имя>» вместе с участниками.

> Установщик не подписан сертификатом, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите **Подробнее → Выполнить в любом случае**.

При первом запуске укажите адрес сервера (например, `http://203.0.113.10:3000`), зарегистрируйтесь, добавьте друга по логину и нажмите **Позвонить**.

## Сервер на домашнем ПК с Windows

Подходит, если провайдер даёт «белый» IP (внешний IP в настройках роутера совпадает с тем, что показывает, например, 2ip.ru). Для 10–15 человек хватит любого ПК.

1. Установите [Node.js](https://nodejs.org) 22.13 или новее.
2. Скачайте проект и запустите установку:
   ```powershell
   git clone https://github.com/IlyaDasler/sozvon.git
   cd sozvon
   powershell -ExecutionPolicy Bypass -File deploy\windows\install-server.ps1
   ```
   Скрипт скопирует сервер в `%LOCALAPPDATA%\SozvonServer`, включит встроенный TURN-сервер, придумает код приглашения и настроит запуск в фоне при входе в Windows. В конце он покажет адрес для друзей и код.
3. Когда Windows спросит про доступ к сети для Node.js, разрешите доступ в частных и общественных сетях.
4. В роутере пробросьте порты на ваш ПК: `3000/TCP`, `3478/UDP`, `49160-49200/UDP`. Там же закрепите за ПК постоянный локальный IP.
5. Друзья ставят приложение, указывают адрес `http://<ваш IP>:3000` и при регистрации вводят код приглашения.

Журнал сервера лежит в `%LOCALAPPDATA%\SozvonServer\logs\server.log`, база — в `data`. Отключить сервер: `deploy\windows\uninstall-server.ps1`.

Встроенный TURN не пересылает трафик на адреса домашней сети, поэтому через него нельзя добраться до других устройств у вас дома.

**Если на ПК включён VPN.** Сервер работает и с включённым VPN: Windows отвечает на входящие подключения через тот же адаптер (Wi‑Fi или кабель), через который они пришли, а не через туннель. Важно одно: друзьям нужен ваш настоящий домашний IP, а не адрес VPN-сервера. Скрипт установки определяет его сам, отправляя запрос мимо VPN. Сайты вроде 2ip.ru при включённом VPN покажут адрес VPN, им верить нельзя. Если IP сменился, просто запустите скрипт ещё раз. На своём ПК подключайтесь к серверу по адресу `http://localhost:3000`.

## Регистрация по почте и вход через Яндекс

Аккаунт создаётся по своей почте: почта, имя и пароль, а на почту приходит шестизначный код, который нужно ввести. Войти потом можно по почте или по логину. Почта — такой же способ входа, как Яндекс: к уже созданному профилю её привязывают в **Настройках → Способы входа** (тоже по коду из письма) и там же отвязывают. На экране входа есть «Забыли пароль?» — новый пароль задаётся по коду из письма. Старые профили с логином и паролем работают как раньше.

Письма отправляет почтовый ящик, указанный на сервере (SMTP). Пока его нет, регистрация по почте и коды не работают — приложение об этом скажет. Ящик для отправки — например, отдельная почта на Яндексе:

1. Заведите ящик (например, `sozvon.noreply@yandex.ru`) и в настройках почты включите доступ почтовым программам (**Все настройки → Почтовые программы**, протокол IMAP).
2. В [Яндекс ID → Безопасность → Пароли приложений](https://id.yandex.ru/security/app-passwords) создайте пароль приложения для почты.
3. Впишите на сервере:

   ```
   SMTP_HOST=smtp.yandex.ru
   SMTP_PORT=465
   SMTP_USER=sozvon.noreply@yandex.ru
   SMTP_PASS=пароль-приложения
   ```

Также можно войти через Яндекс: приложение откроет страницу входа в своём окне, а после подтверждения окно закроется само. К уже созданному профилю Яндекс привязывается в **Настройках → Вход через сервисы**. Если на сервере включён код приглашения, он нужен и для первой регистрации. Кнопка «Войти через Яндекс» появляется, только если на сервере указаны ключи:

1. Откройте [oauth.yandex.ru/client/new](https://oauth.yandex.ru/client/new) и войдите в Яндекс ID.
2. Название сервиса: `Созвон`, иконка — по желанию.
3. Платформа: **Веб-сервисы**, Redirect URI: `http://localhost:47615/callback`.
4. В разделе доступов отметьте **Доступ к адресу электронной почты** (`login:email`) и **Доступ к логину, имени и фамилии, полу** (`login:info`).
5. Нажмите **Создать приложение** и скопируйте **ClientID** и **Client secret**.

### Куда вписать ключи и почтовый ящик

- **Сервер на VPS:** в `/etc/sozvon.env` (`YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `SMTP_*`), затем `systemctl restart sozvon`.
- **Сервер на домашнем ПК:** откройте в Блокноте `%LOCALAPPDATA%\SozvonServer\oauth.cmd`, вставьте значения после знаков `=` и запустите `deploy\windows\install-server.ps1` ещё раз — он перезапустит сервер.
- **Для разработки:** задайте те же переменные окружения.

Порт `47615` открывается только на время входа через Яндекс и только на этом компьютере. Пробрасывать его в роутере не нужно.

## Свой сервер на VPS

Подойдёт любой VPS с Linux (Timeweb Cloud, Selectel, REG.RU, Beget и т.п.), хватит 1 ядра и 1 ГБ памяти.

1. Установите Docker: `curl -fsSL https://get.docker.com | sh`
2. Скачайте проект и настройте:
   ```bash
   git clone https://github.com/IlyaDasler/sozvon.git
   cd sozvon/deploy
   cp .env.example .env
   nano .env        # впишите PUBLIC_IP и TURN_SECRET
   docker compose up -d
   ```
3. Откройте порты в файрволе: `3000/tcp`, `3478/tcp+udp`, `49160-49200/udp`.
4. В приложении укажите адрес `http://<IP-сервера>:3000`.

**HTTPS (рекомендуется).** Без него пароли идут по сети в открытом виде. Если есть домен, направьте его на IP сервера, впишите в `.env` строку `DOMAIN=ваш.домен` и запустите `docker compose --profile https up -d`. Сертификат выпустится автоматически, а адрес в приложении будет `https://ваш.домен`. Заодно появится веб-версия: друзья смогут зайти из браузера.

Данные (база и ключ подписи токенов) лежат в Docker-томе `sozvon-data`.

## Разработка

Нужен Node.js 22.13 или новее.

```bash
# сервер
cd server
npm install
npm start           # http://localhost:3000 (в приложении и тестах — http://127.0.0.1:3000)
npm test            # автотесты API и сигналинга

# приложение (в другом терминале)
cd client
npm install
npm start
npm start -- --profile=friend   # второе окно под другим аккаунтом, чтобы проверить звонок на одном ПК
npx electron scripts/e2e-call.js  # сквозной тест звонка: звук, камера, микрофон
npx electron scripts/e2e-status.js # статусы и уведомления на двух окнах
npx electron scripts/e2e-friends.js # друзья: заявки, принятие, отказ, блокировка
npx electron scripts/e2e-chat.js  # чат: разметка, смайлики, файлы и картинки, превью ссылок, карточка профиля (сервер — с LINK_PREVIEW_ALLOW_PRIVATE=1)
npx electron scripts/e2e-room.js  # сквозной тест комнаты на троих: чат, голос, камера, экран, роли, кик на время, бан, приглашение, переход между каналами (E2E_SKIP_FULLSCREEN=1 — пропустить шаг «во весь экран», если Windows не даёт окну полноэкранный режим)
npx electron scripts/e2e-hubs.js  # сходки: собрать, позвать друга, вступление, комнаты внутри, группа перетаскиванием, раскладка у каждого своя, список участников, темы и узкое окно
npx electron scripts/e2e-tray.js  # трей: крестик прячет окно, значок с запуска, щелчок и меню возвращают окно, повторный запуск, «Выйти» (запускает настоящий main.js, сервер не нужен)
npx electron scripts/e2e-update.js # уведомление об обновлении: плашка и точка без окна, «Что нового», «не сейчас»
npx electron scripts/e2e-oauth.js # сквозной тест входа через Яндекс и регистрации по почте (с поддельным Яндексом)
npx electron scripts/e2e-oauth-window.js # окно входа Яндекса закрывается само после входа
E2E_OLD=папка/client npx electron scripts/e2e-compat.js # звонок и комната со старой версией (папка — из git archive vX.Y.Z client/renderer client/preload.js)
npm run dist        # собрать установщик в client/dist
```

> Если проект лежит в очень глубокой папке, сборка установщика может упасть с ошибкой `could not open file ... .nsh`: NSIS не понимает пути длиннее 260 символов. Перенесите проект поближе к корню диска, например в `C:\dev\sozvon`.

Настройки сервера через переменные окружения:

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3000` | порт сервера |
| `DATA_DIR` | `server/data` | где хранить базу, аватарки и файлы из чата |
| `JWT_SECRET` | генерируется | ключ подписи токенов входа |
| `STUN_URLS` | `stun:stun.l.google.com:19302` | STUN-серверы через запятую |
| `TURN_URLS` | — | TURN-серверы через запятую |
| `TURN_SECRET` | — | общий секрет с coturn (`static-auth-secret`) |
| `TURN_EMBEDDED` | — | `1` — запустить встроенный TURN (UDP) прямо в сервере |
| `PUBLIC_IP` | — | внешний IP; со встроенным TURN из него собираются адреса STUN/TURN |
| `INVITE_CODE` | — | если задан, регистрация возможна только с этим кодом |
| `LINK_PREVIEW_ALLOW_PRIVATE` | — | `1` — разрешить превью ссылок на локальные адреса; только для тестов |

Релиз: поднимите версию в `client/package.json`, затем выполните `git tag v1.2.0 && git push --tags`. GitHub Actions соберёт установщик и приложит его к релизу вместе с `latest.yml`. Приложения увидят новую версию при следующем запуске или по кнопке «Проверить обновления». Текст описания релиза показывается в окне обновления как «Что нового», так что пишите его для пользователей. Версия в теге должна совпадать с версией в `package.json`, а релиз не должен быть черновиком или пре-релизом, иначе приложения его не увидят.
