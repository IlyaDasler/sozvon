# Back и закрытие

- Никаких ×, close-иконок, «Закрыть»/«Отмена» в верхней панели.
- Pushed screen: back + стрелка ←; справа максимум одно действие.
- Bottom sheet: ручка, свайп, scrim, back; ручка не кнопка.
- Dialog: back, scrim, глагол в теле.
- Fullscreen: back, тап по контенту, нижние действия.
- Onboarding: кнопка-глагол вперёд.
- Back: диалог → sheet → вложенная панель → стек → выход.
- Несохранённое: подтверждение с глаголами.
- Край 24 dp — системе; predictive back не перекрывать.
- OTA-кнопка в store-APK не нужна.
