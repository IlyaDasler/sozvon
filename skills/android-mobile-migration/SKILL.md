# Android Mobile Migration

Три роли в одном лице, зоны ответственности не смешиваются:

1. **Дизайн-директор** — планка Google Material 3, Apple HIG, Linear, Telegram, Discord, Stripe. Проектирует точно, а не «красиво»: меньше элементов, выше плотность смысла, безупречные края.
2. **Senior Android front-end engineer** — Capacitor/WebView, WindowInsets, edge-to-edge, IME, back, container queries, производительность.
3. **QA с регрессным мышлением** — ищет, где сломается. Результат без прогона по матрице не существует.

## Главный принцип

**Функционал неизменен. Дизайн — новое мобильное воплощение. Десктопный код — источник поведения, а не шаблон вёрстки.**

Нельзя удалять, прятать «на потом» или отключать фичу. Не помещается — переосмысли размещение.

## Платформа проекта

- Оболочка: Capacitor 8 + Android WebView, APK.
- `minSdk 24`, `targetSdk 36`; при targetSdk ≥ 35 edge-to-edge принудительный.
- Телефоны 320–480 dp, фолды 600–900 dp, планшеты 768–1366 dp, split screen.
- Классы окна: compact `<600`, medium `600–839`, expanded `840–1199`, large `1200+`.
- Стек: ванильный JS + CSS, без React/Vue; стили — CSS-файлы в `client/renderer`.
- Бизнес-логика, API, схема данных и аналитика не меняются.

## Критерии дизайна

1. **Отнимать, а не добавлять.** Каждый элемент оправдывает существование.
2. **Одна идея на экран.** Один главный акцент.
3. **Честность.** Кнопка выглядит нажимаемой, поле — вводимым, переключатель — переключаемым. Никаких псевдо-3D и декоративного стекла.
4. **Точность краёв.** Оптическое выравнивание, шаг сетки, одна базовая линия.
5. **Тишина.** Никаких лишних линий, рамок, бейджей и иконок «для красоты».
6. **Один осмысленный жест.** Анимация подтверждает изменение, а не развлекает.
7. **Типографика — главный материал.** Иерархия размером, весом, цветом и воздухом, не рамками.

Плотность на мобильном — полезная, не просторная. Пустота — инструмент акцента.

## Анти-слоп: чёрный список

Ни один пункт не появляется без письменного обоснования.

**Градиенты и цвет**

- фиолетово-синие AI-градиенты;
- цветные тени и glow;
- градиентный текст;
- кислотный акцент более 10% площади;
- больше одного акцентного цвета.

**Формы и материалы**

- glassmorphism и backdrop-blur «потому что модно»;
- одинаковый радиус 16–20 px на всех блоках;
- стеклянные карточки с обводкой 1 px белого 10%;
- тень на каждом блоке;
- радиусы и тени вне токенов.

**Композиция**

- центрирование всего экрана подряд;
- hero с блобами, точками, парящими карточками;
- три колонки фич с иконками в кружках;
- заголовок 40–56 px на мобильном;
- декоративные бейджи «NEW», «AI-powered», «Beta»;
- стоковые иллюстрации и 3D-рендеры;
- фейковые метрики, отзывы, логотипы.

**Android-специфично**

- шторка со свайпом без системного back;

**Детали**

- эмодзи вместо иконок и в интерфейсных текстах;
- дефолтные браузерные select/checkbox/scrollbar;
- shimmer-скелетон на каждом экране;
- анимация всего, что технически анимируется;

## Feature Parity

До кода обязательна таблица:

| Экран | Фича | Мобильная реализация | Где в UI |
|---|---|---|---|

Ни одна фича не исчезает. Для каждой определяются:

- основное действие в нижних 40% высоты;
- вторичные действия — tap/long-press/bottom sheet;
- состояния: default, pressed, focus, disabled, loading, error, empty, offline;
- сохранение позиции скролла и введённого текста при возврате.

## Навигация

- Не более 5 пунктов нижней навигации.
- Глубина стека — не больше 3 уровней до возврата.
- Вторичные сценарии — шторки/модалки, не новые экраны.
- Шторка ≤90dvh, с ручкой, закрывается свайпом и системным back.
- Планшет/развёрнутый фолд при ≥840 dp — master-detail или две колонки, боковая навигация вместо нижней.
- Деструктивные действия отделены и подтверждаются глаголом («Удалить» / «Оставить»).

## Android: safe-area, edge-to-edge, IME, back

- `viewport-fit=cover`; `env(safe-area-inset-*)` плюс фолбэк из `--safe-area-inset-*`.
- Верхняя панель, шторка, dropdown и тост не могут перекрывать системный трей. Это блокирующий дефект.
- `WindowCompat.setDecorFitsSystemWindows(false)`; прозрачные status/navigation bar; `shortEdges` для cutout.
- Нижняя навигация и composer учитывают gesture bar.
- Поля: `font-size ≥16px`, `inputmode`, `enterkeyhint`, `autocomplete`.
- Клавиатура: VisualViewport; липкие панели прячутся; поле не перекрывается.
- Системный back закрывает sheet/модалку/раздел, а не выбрасывает из приложения. Прогрессивный стек:

```text
sheet → section → settings root → room → channel list → exit
```

- Свайп от края 20–24 px не перехватывается.
- `touch-action: manipulation`; tap-highlight отключён; двойной тап не зумит.

## Складные устройства и ресайз

- Свёрнуто: узкий высокий экран, нижние действия достижимы.
- Развёрнуто: короткая сторона 600–900, отдельный двухколоночный layout.
- Полураскрыто: контент не на петле; верх — контент, низ — управление.
- Spanning: `(horizontal-viewport-segments: 2)`, `(vertical-viewport-segments: 2)`, `env(viewport-segment-*)` с безопасным фолбэком.
- `navigator.devicePosture` — прогрессивное улучшение, не зависимость.
- Ориентация/складывание — ресайз, не перезагрузка. `location.reload()` запрещён.
- Состояние, скролл, текст, открытые модалки и медиа сохраняются.

## Мобильный моушен

Десктопные анимации не переносятся.

**Запрещено:** параллакс, scroll-jacking, reveal-on-scroll с большими смещениями, mousemove, курсорные эффекты, длинные интро, анимация blur/больших теней, бесконечные декоративные циклы.

**Тайминги**

| Действие | Длительность |
|---|---|
| Отклик на нажатие | 80–120 мс, scale 0.97–0.98 |
| Переключатель/чекбокс | 150–200 мс |
| Панель/шторка | 250–320 мс |
| Переход экрана | 250–300 мс |
| Fade контента | 120–160 мс |
| Тост | вход 180, показ 2500, выход 150 мс |

Easing: `cubic-bezier(0.2, 0, 0, 1)`; вход decelerate, выход accelerate; максимум 350 мс.

Правила:

- только `transform`, `opacity`, при необходимости `clip-path`;
- первый кадр — из текущего состояния;
- нет layout shift и обрезки;
- переходы отменяемы;
- при возврате анимация не повторяется;
- `prefers-reduced-motion: reduce` — мгновенная смена или fade ≤100 мс.

## Производительность

- FCP <1.8 с на среднем Android/4G; INP <200 мс; CLS = 0; 60 fps.
- Ни одной длинной задачи >50 мс на критическом пути.
- Списки >50 — виртуализация; иначе `content-visibility: auto`.
- Позиция скролла сохраняется при изменениях выше.
- Изображения: `width/height` или `aspect-ratio`, `srcset/sizes`, lazy, placeholder.
- Шрифты: `font-display: swap`, только используемые начертания.
- Нет водопадов запросов; кэш первого экрана; backoff.
- Нет утечек листенеров и таймеров.
- Слабый Android: без тяжёлого blur, больших теней и множественных анимаций.

## Токены

Всё через переменные:

- цвета: surface/on-surface/muted/accent/danger/success;
- радиусы: 3–4 значения;
- тени: 2–3 уровня без цвета;
- отступы 4/8/12/16/24/32;
- длительности и easing;
- z-index: content/sticky/nav/backdrop/sheet/modal/toast.

Никаких магических чисел в компонентах. Новые цвета, шрифты и радиусы — только по согласованию.

## QA: матрица

Ширины: `320, 360, 375, 390, 393, 412, 430, 600, 673, 768, 820, 1024, 1180, 1366`.

Высоты ландшафта: `640×360, 844×390, 915×412, 932×430`.

Фолд: свёрнут, развёрнут, полураскрыт, две колонки/spanning. Обе ориентации.

Данные: загрузка, пусто, ошибка, нет сети, очень длинный текст, длинный список, битые картинки.

Ввод: клавиатура, автозаполнение, вставка длинной строки.

Доступность: видимый фокус, контраст ≥4.5:1, тач-зоны ≥44, reduced-motion.

## QA: стоп-лист

1. Горизонтальный скролл.
2. Обрезанные тени/тултипы/меню из-за overflow.
3. Контент под вырезом/gesture bar/системными панелями.
4. `100vh`.
5. Автозум iOS при `font-size <16px`.
6. Клавиатура перекрывает поле/липкую кнопку.
7. Прыжок наверх при закрытии модалки.
8. CLS при загрузке шрифта/картинок/данных.
9. Залипший hover.
10. Скроллбар дёргает layout.
11. Конфликт z-index.
12. Двойной тап зумит.
13. Фиксированная высота режет текст.
14. Тач-зоны <44 или слипшиеся.
15. Карусель конфликтует с back-свайпом.
16. Анимация не тех свойств.
17. Модалка шире/выше viewport.
18. Двойной скролл.
19. Голое пустое/ошибочное состояние.
20. Разный вид 360/390 из-за хардкода.
21. Потеря состояния при повороте/складывании.
22. Повторная анимация при возврате.
23. Гонка состояний при быстрых тапах.
24. Любой пункт анти-слопа.

## Процесс

1. **Аудит без кода:** Feature Parity, что не переносится, что переизобретается, карта экранов, риски. Ждать «ок».
2. **Токены и сетка** отдельным шагом.
3. **Экраны партиями 2–3**, полный код, короткий отчёт.
4. **Моушен-спека** до реализации.
5. **QA** по стоп-листу и матрице.
6. **Финальная сборка + DoD.**

## Definition of Done

- Все фичи доступны, ничего не потеряно.
- Нет горизонтального скролла, обрезки, наложений, CLS.
- Десктопные анимации не используются; мобильный моушен 80–350 мс, только transform/opacity.
- Корректно 320–1366, все состояния фолда, обе ориентации.
- Состояние сохраняется при ресайзе/повороте/складывании.
- Safe-area, клавиатура, системный back учтены.
- `prefers-reduced-motion` работает.
- Все состояния спроектированы; дефолтных браузерных элементов нет.
- Нет анти-слопа, TODO, заглушек и мёртвого кода.
- Код запускается без точечных правок.
