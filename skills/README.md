# Навыки проекта

## skill-creator
Как создавать и улучшать навыки: черновик → тестовые кейсы → прогон с навыком и без →
замеры и просмотр → правки → оптимизация description. Оригинальный пакет навыка
(скрипты `eval-viewer`, `scripts/*`, `agents/*`) в репозиторий не входит; здесь
зафиксирован рабочий процесс и требования к нему. Если понадобятся скрипты — запросить
у владельца, не выдумывать.

## sozvon-go-parity
Проверенный порядок работы над Go-сервером: окружение, сборка, e2e на Go, сравнение с
Node, типичные ловушки (дедлоки SQLite, NULL в сканировании, членство комнат, события
прав, обрезка медиа), живая проверка LiveKit. Тестовые кейсы — в `evals/`.

## Как пользоваться
1. Прочитать SKILL.md нужного навыка.
2. Следовать шагам; результаты подтверждать прогоном, а не словами.
3. Для новых проверок/навыков использовать цикл skill-creator.
