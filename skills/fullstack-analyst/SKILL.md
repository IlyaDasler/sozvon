# Fullstack-аналитик «Созвона»

Цель — не пересказать код, а найти проверяемую причину или риск и подтвердить её тестом,
логом или замером.

## Как работать

1. **Очертить путь данных.** Клиент → preload/IPC → HTTP/WS → Go-хендлер → store/SQLite →
   событие обратно в клиент. Для медиа — WebRTC/LiveKit, для E2EE — где именно шифруется.
2. **Воспроизвести или найти доказательство.** Сначала факт: лог, e2e, запрос, замер. Не
   утверждать «должно работать» без прогона.
3. **Проверить границы.** Приватные комнаты, права, E2EE (сервер не видит текст), гонки
   при перерисовке, порядок загрузки renderer-скриптов, старый кэш/старые клиенты.
4. **Измерить.** Для UI — `e2e-layout/look/spacing`; для API — Go-тест/контракт; для
   производительности — время, память, FPS. Записывать конкретные числа.
5. **Сделать минимальный фикс.** Сначала тест, потом изменение; после — тот же тест и
   соседние сценарии.
6. **Отчитаться фактами.** Что проверил, что нашёл, чем подтвердил, что осталось
   непроверенным — отдельной строкой.

## Проектные ограничения

- Сервер только Go; Node-бэкенд не возвращать.
- E2EE: сервер не может искать/записывать содержимое; любые такие фичи — только на клиенте.
- Продакшен и релизы — только с явного согласия; перед релизом обязателен реальный macOS updater e2e.
- Не трогать установленную у пользователя версию приложения.
- Сначала измерить, потом утверждать; не выдумывать API, поля и поведение.

## Полезные команды

```powershell
# Go
cd server-go; go test ./...; go vet ./...

# клиент
cd client; npm test
node scripts/run-e2e.js e2e-spacing e2e-hubs e2e-chat

# macOS updater (только на macOS, после dist:mac)
node scripts/e2e-mac-update.js
```

## Красные флаги

- `state`/`store` используются классическими скриптами до ES-модулей — не выносить один
  `state` без загрузчика или полного перевода renderer на модули.
- Приватная комната и `room:updated`/`room:removed` — проверять аудиторию события.
- `map` участников голоса — сортировать по `joinedAt`, иначе UI переставляется.
- `%TEMP%`/AppData могут быть недоступны в урезанной сессии — проверять путь записи.
- Не считать «зелёный unit» доказательством работы UI: нужен e2e.
