Созвон 3.0 · дизайн-система Тема:

Созвон 3.0 — UI-кит

Жидкое стекло: слои, блик за курсором, радужная кромка. Плоские контролы, крупные скругления, тёмные полупрозрачные поверхности. Токены совпадают с приложением — можно переносить в Figma один в один.

Как читать витрину

Компоненты слева направо показывают состояния: обычное, наведение, нажатие, выключено. Все размеры кратны 4: 4 / 8 / 12 / 16 / 20. Радиусы: 6 / 12 / 16 / 20.

Структура дизайн-системы

1. Принципыстекло для действия, заливка для значения, один ритм движения 2. Токеныцвет, типографика, радиусы, отступы, движение, стекло 3. Темышесть палитр, переключатель сверху страницы 4. Компонентыкнопки, поля, свитчеры, вкладки, окна, меню, тосты 5. Экранычат, комната, звонок, настройки, профиль, вход 6. Доступностьфокус, reduced-motion, reduced-transparency

Принципы

  1. Стекло — для того, через что действуют: кнопки, меню, окна, тосты.
  2. Плоская заливка — для того, что несёт значение: поля, чекбоксы, радио, ползунки.
  3. Акцент и опасность — сплошные: цвет и есть сообщение, прозрачность его размывает.
  4. Один ритм: 120 / 180 / 240 / 320 мс и две кривые на весь интерфейс.
  5. Геометрия проверяется тестом: центровка иконок, высоты шапок, отсутствие переполнений.
