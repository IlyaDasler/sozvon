# Контракт API и WebSocket

Снято с работающего Node-сервера скриптом `_tools/contract-snapshot.js` (фаза 0 перехода на Go).

- `api.json` — 29 вызовов: метод, путь, код ответа и нормализованное тело.
- `ws-events.json` — 44 имени событий, которые сервер отправляет клиентам.

## Что нормализовано

Идентификаторы, токены, время и хеши файлов заменены заглушками (`0`, `<value>`, `<jwt>`,
`<hex>`, `<api/file>`). Поэтому сравнивать нужно **форму и коды**, а не конкретные значения.

## Как пользоваться при переходе на Go

1. Поднять Go-сервер на чистой БД и прогнать тот же сценарий:
   `CONTRACT_BASE=http://127.0.0.1:3000/api node _tools/contract-snapshot.js`
   (скрипт всегда пишет в `server/contract/api.json` — сохраните эталон в git и сравните diff).
2. Любое расхождение в ключах, типах или кодах — блокер для переключения.
3. Список `ws-events.json` — минимальный набор событий, которые Go обязан отправлять
   с теми же именами и полями.
